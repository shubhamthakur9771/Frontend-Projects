## 📖 Overview

This project is a YouTube-inspired frontend practice space focused on structuring a video browsing page and understanding how different CSS layout systems solve similar interface problems. The `Flex` and `Grid` folders keep the two approaches separate so that their markup and styling can be explored independently.

It is a learning exercise rather than a production YouTube client: the pages use local sample thumbnails and channel pictures and do not connect to YouTube services or APIs.

## 🧰 Built with

- **HTML5** for page structure.
- **CSS3** for typography, spacing, colors, and component styling.
- **CSS Flexbox** for one-dimensional alignment and distribution.
- **CSS Grid** for two-dimensional row-and-column layouts.
- **Local image assets** for video thumbnails and channel pictures.
- **Roboto** typography is referenced by the page styling.

## 🚀 Run locally

### Option 1 — Open directly

Open either page in a browser:

- [Flexbox YouTube page](./Flex/youtube.html)
- [Grid YouTube page](./Grid/youtube.html)

### Option 2 — VS Code Live Server

1. Open `Youtube-Clone-Practice` in VS Code.
2. Open `Flex/youtube.html` or `Grid/youtube.html`.
3. Right-click and choose **Open with Live Server**.

No build command or dependency installation is configured for this static HTML/CSS project.

## 🎯 Learning outcomes

Use this project to practise: comparing Flexbox and Grid, organizing stylesheets, using reusable image assets, building a repeated card-like video layout, and separating page structure from presentation.
