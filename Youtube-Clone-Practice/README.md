## 📖 Overview

A frontend practice project that recreates a YouTube-style video browsing layout while exploring core HTML and CSS concepts.

The project keeps two layout approaches separate so that Flexbox and CSS Grid implementations can be explored and compared.

## ✨ What’s included

- **Flexbox:** video layout and alignment practice.
- **CSS Grid:** grid-based video layout practice.
- **Introductory HTML:** simple pages covering text, buttons and basic links.
- **Reusable assets:** thumbnail images and channel pictures used by the layouts.
- **Separate stylesheets:** styles organized by page and component.

## 🧰 Technologies

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Google Fonts (Roboto)
